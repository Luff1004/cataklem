# 카타클렘 (CATAKLEM)

모바일 세로 화면용 서바이벌 로그라이트. 무너진 하늘 아래, 잉크 괴물 떼 사이에서 불씨 하나로 버틴다.

- 플레이: https://luff1004.github.io/cataklem/
- 조작: 화면 아무 데나 대고 끌면 이동, 공격은 자동
- 무기 12종과 진화, 장신구 10종, 캐릭터 19명
- 보스전 전용 무기 6종, 장신구 8종 (무기 3칸, 장신구 4칸)
- 작업대에서 포탈을 만들어 보스 9종과 싸운다. 마지막은 UNKNOWN

## 빌드

`src/page.html`과 `src/js/*.js`를 고친 뒤 `./build.sh`를 실행한다.

- `docs/index.html`: 공개용 (GitHub Pages)
- `index.html`: 로컬 테스트용 (보스 포탈 전부 열림)
